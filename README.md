# PROJECT WINDMILL - Loto7 Combination Generator

ロト7の過去データから「軸数字」を選び、条件フィルターを通した5つの組み合わせをランダムに生成する、小さな Streamlit アプリです。API は使わず、Python だけで動きます。

> 確率の風車は気まぐれに回ります。

## 先に断っておくこと

**これは当せんを予測するツールではありません。エンタメ用の生成器です。**

- ロト7の抽せんは毎回独立していて、どの7数字の組み合わせも当せん確率は同じです。
- 軸数字の選び方も、条件フィルターも、当せん確率を変えるものではありません。
- アプリの副題にある「アスベル式・未来逆算理論」は作品としての世界観で、下の処理に予測力があると主張するものではありません。

フィルターが当せんに効かないことは、手元で確かめられます。

```bash
python filter_backtest.py
```

直近100回の当せん番号のうち、フィルターを通ったのは73回(73.0%)でした。一方、無作為に選んだ7数字は約68.5%が通ります。差は100回分の誤差(±4.4%程度)に収まっていて、フィルターが当せん番号を絞り込んでいる証拠にはなりません。(`filter_backtest.py` も、実行時にデータ取得を試みます。)

```python
import random
from combo_engine import validate_combination

rng = random.Random(0)
n = 200_000
print(sum(validate_combination(sorted(rng.sample(range(1, 38), 7))) for _ in range(n)) / n)  # 約0.685
```

## 何をしているか

1. **グループ分け**: 直近10回の本数字の出現回数で、1〜37を3つに分けます。出現の少ない10個(cold)、中間の17個(mid)、よく出ている10個(hot)です。同じ出現回数の数字は、順序をランダムに決めます。
2. **軸の選定**: cold・mid・hot から、1つずつランダムに選びます。
3. **生成**: 軸を含む組み合わせをランダムに作り、条件フィルターを通ったものを5つ採用します。5つの買い目は、すべて同じ3つの軸を含みます。

### 条件フィルター

| 条件 | 内容 |
|---|---|
| 合計 | 90〜170 |
| 奇偶比 | 3:4 / 4:3 / 2:5 / 5:2 |
| 連続番号 | 2連まで(3連以上は除外) |
| 高低比 | 1〜18 と 19〜37 が 3:4 / 4:3 / 2:5 / 5:2 |

## 使い方

```bash
pip install -r requirements.txt

# 画面で使う
streamlit run app.py

# ターミナルで使う
python run.py
```

実行のたびに過去データを取得します。取得したデータは、件数・連番・数字の範囲を検証してから `loto7_data.csv` に保存します。検証に通らない場合や、取得できなかった場合は、保存済みの `loto7_data.csv` を使い、レポートに警告を表示します。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `app.py` | Streamlit の画面 |
| `run.py` | ターミナルから実行する入口 |
| `combo_engine.py` | 軸の選定・組み合わせ生成・条件フィルター・レポート作成 |
| `fetch_data.py` | 過去データの取得・検証・保存 |
| `filter_backtest.py` | 過去の当せん番号が、条件フィルターをどれだけ通るかを調べる |
| `analyzer.py` | 直近の出現頻度などから数字別スコアを表示する単体スクリプト(アプリ本体からは使っていません) |
| `loto7_data.csv` | 過去の当せん番号(取得に失敗したときの予備を兼ねる) |

## データの出典

過去の当せん番号は、[mk-mode.com](https://www.mk-mode.com/) が公開している CSV を取得しています。正式な当せん番号は、みずほ銀行の宝くじのページで確認してください。データの正確性は保証しません。出典サイトの利用条件に従ってください。
